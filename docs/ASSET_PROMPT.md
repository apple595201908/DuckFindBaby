# 鴨鴨基因實驗室：美術生成規格

角色、場景與介面均為本專案原創。七張參考圖只用來理解配方、色彩方向與「候選角色升起再落下」的遊玩節奏，沒有直接使用或描摹參考作品的角色、介面、文字、標誌或像素內容。

## 鎖色鴨鴨圖集

鴨鴨不是由影像模型重新畫 14 次，而是從專案原創黃鴨母版建立固定身體遮罩，再以 `scripts/generate_gene_palette_sprites.sh` 平塗 `docs/GENE_COLOR_SPEC.md` 的 14 個 HEX。眼睛、腹部、嘴喙與腳保持固定色，因此答案色不受光影與生成差異干擾。

## DNA 動態背景

目前版本不再使用帶有愛心反應爐的完整場景圖。背景只由兩層組成：

1. CSS 淡藍至淡紫漸層，提供穩定、低細節的基底。
2. `public/game/assets/dna-helix-ambient.png` 單一透明 DNA 圖層。

DNA 圖層以 `118vmax` 為視覺尺寸，跨越手機與平板的大部分背景；透明度固定為 `0.14`，置於所有遊戲介面後方，並設定 `pointer-events: none`。28 秒動畫只使用 `transform` 做小幅位移、縮放與旋轉，不使用即時模糊或濾鏡，因此不會攔截選單、干擾辨色或造成明顯掉幀。

背景素材規格：透明 PNG、無文字、無角色、無愛心、無按鈕、無瀏覽器外框，只有青藍與粉紫發光 DNA 雙螺旋。候選角色、題目文字與觸控卡片全部由程式疊加，不把答案或 UI 烘焙進背景。
